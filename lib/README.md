# 🌸 CysterEase

CysterEase is a Flutter-based wellness application designed to support individuals with PCOS/PCOD by helping them track daily health habits and build a balanced lifestyle.

## ✨ Features
- 💤 Sleep tracking with visual trends
- 🥗 Diet and habit awareness
- 📊 Graphical insights using charts
- 🔐 Firebase Authentication
- ☁️ Cloud Firestore integration
- 🎨 Clean and calming UI

## 🛠 Tech Stack
- Flutter (Dart)
- Firebase Authentication
- Cloud Firestore
- fl_chart

## 🚀 Getting Started
1. Clone the repository
2. Run `flutter pub get`
3. Add your own Firebase configuration files
4. Run the app using `flutter run`

## 📌 Note
Firebase configuration files are not included for security reasons.
